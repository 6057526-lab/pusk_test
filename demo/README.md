# Оболочка для показа

Открыть `index.html` через HTTP. Приложение занимает весь viewport, без верхней
DEV-панели и рамки. Бургер → внизу «Варианты прототипа» → выбрать копию.
Меню доступно также на внутренних экранах. Переключение сохраняет сеансы iframe.
«Начать заново» требует подтверждения и сбрасывает только выбранный вариант.

С 13 октября 2026 в выборе X1, текущий X2 и новый X3 по решению пользователя.
Текущий X2 — бывший X4 (`question-pager`); поменялось отображаемое название.
Новый X3 — «Моё предприятие», `enterprise-audit`, независимый маршрут по выбранному
второму макету. Ссылки: `index.html#question-pager`, `index.html#baseline`,
`index.html#enterprise-audit`. По умолчанию — X2.
Текущая мобильная копия и прежние X2 (`product-proposal`) / X3 (`visit-workspace`)
сохранены в своих каталогах и запускаются
напрямую, но не включены в выбор оболочки. Их файлы и черновики не удаляются.

Все папки размещаются на одном origin. Shell добавляет оформление viewport и
контролы меню в DOM iframe после загрузки, без изменения файлов приложений,
без подключения общей бизнес-логики и без переноса ответов между версиями.
Прямые ссылки на приложения продолжают работать самостоятельно.

Демо опубликовано на Railway: https://pusk-demo-production.up.railway.app/.
Сервис `pusk-demo`, проект `pusk_test`, окружение `production` получает код из
`6057526-lab/pusk_test`, ветка `main`. После отправки изменений дождаться успешного
deployment и проверить опубликованные ресурсы; один push ещё не подтверждает обновление.
Сохранять относительную структуру demo/, prototype/, variants/.
Ссылка на текущий X3: `/demo/index.html#enterprise-audit`, на X2 —
`/demo/index.html#question-pager`. localhost доступен только на текущем компьютере.
