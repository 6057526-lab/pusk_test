# Оболочка для показа

Открыть `index.html` через HTTP. Приложение занимает весь viewport, без верхней
DEV-панели и рамки. Бургер → внизу «Варианты прототипа» → выбрать копию.
Меню доступно также на внутренних экранах. Переключение сохраняет сеансы iframe.
«Начать заново» требует подтверждения и сбрасывает только выбранный вариант.

Ссылки на конкретную версию: `index.html#question-pager`, `#visit-workspace`,
`#product-proposal`, `#current-mobile`, `#baseline`. По умолчанию — текущая мобильная.
Названия соответствуют X4, X3, X2, текущей мобильной копии и исходнику X1.

Все папки размещаются на одном origin. Shell добавляет оформление viewport и
контролы меню в DOM iframe после загрузки, без изменения файлов приложений,
без подключения общей бизнес-логики и без переноса ответов между версиями.
Прямые ссылки на приложения продолжают работать самостоятельно.

Публикация пока не выполнена. Для будущего статического хостинга сохранять
относительную структуру demo/, prototype/, variants/. localhost доступен только
на текущем компьютере, его нельзя посылать продакту как внешнюю ссылку.

Старые qa-скрипты проверки верхней DEV-панели описывают прежнюю оболочку.
Актуальная проверка оболочки и регрессии 48/48: `qa/release.js`.
