# Проверка перед продуктовым просмотром

23 сентября 2026. Локальный Chromium / Playwright CLI.

## Исправления

- X4: завершение зависело от последнего вопроса по порядку. При заполнении
  последнего пропуска в середине списка 48/48 не меняли действие «Далее».
  Теперь при отсутствии пропусков кнопка с любого вопроса открывает проверку.
  Проверены также возврат из сводки к ответам и повторное завершение.
- Верхняя DEV-панель и рамка удалены. Варианты доступны внизу бургер-меню.
  Меню доступно с внутренних экранов; iframe занимает весь viewport.
- Исправлен сброс X3/X4 через оболочку: удаление ключа происходит после
  завершения обработчиков клика приложения, чтобы автосохранение не восстановило
  старый черновик перед перезагрузкой.

## Результаты

| Вариант | Проверено |
|---|---|
| X1 | Запуск по исходному пути, меню, начало визита; SHA-256 совпадает с фиксацией |
| Текущая мобильная | Реквизиты, согласие, черновик, причины/комментарий, 48 вопросов, валидация, завершение, отчёт, документ; повторный визит, фильтры и отказ в доступе |
| X2 | Выбор ПБО, задачи, черновик, пропуски, 48 ответов, сводка, возврат/отмена/подтверждение, отчёт |
| X3 | Прямой старт, блоки, сохранение после перезагрузки, причины/комментарий, пропуски, 48 ответов, завершение и восстановление отчёта |
| X4 | Все 48 вопросов, кнопки и обработчики свайпа, восстановление, отчёт; отдельная регрессия последнего пропуска в середине |
| Оболочка | Пять вариантов через бургер, сохранение экрана при переключении, сброс X4, ширины 334/390/768/1280, отсутствие внешней рамки |

Обнаруженные ошибки тестовых селекторов исправлены. Native confirm в Playwright
CLI завершает выдачу до результата всей функции; состояние после сброса
дополнительно проверено отдельным вызовом (пустой ключ X4, экран «Начать визит»).

Сценарии приложений находятся в их каталогах; актуальные сценарии оболочки:
`demo/qa/current-start.js`, `demo/qa/release.js`.
Скриншоты: `output/playwright/release-x4.png`, `release-menu.png`.

## Что остаётся за границами

Это готовность локального кликабельного демо к просмотру, не промышленная приёмка.
Не проверены физические телефоны, Safari, экранная клавиатура и работа со скринридером.
PDF остаётся HTML-имитацией; серверное сохранение и бизнес-расчёты не реализованы.
Внешняя публикация не выполнена. Ссылка 127.0.0.1 работает только на этом компьютере.
