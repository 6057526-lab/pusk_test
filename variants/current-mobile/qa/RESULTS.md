# Проверка подготовительной мобильной версии

Дата: 2026-09-23. Браузер: Chromium через Playwright CLI.

Пройдены сценарии:

- `setup-and-isolation.js`: независимость iframe, перезапуск отдельной копии,
  исходный интерфейс, обязательность ПБО, календарь, поиск, перенос реквизитов,
  переход от согласия к задачам.
- `flow.js`: черновик, несколько причин, комментарии, 39 + 9 вопросов,
  обязательность ответов, переключение разделов, отмена и подтверждение завершения,
  появление задачи результатов, карточка отчёта и просмотр документа.
  Ошибок JavaScript в этом проходе не обнаружено.
- `restart-and-reports.js`: закрытие процесса, фильтр отчётов, реквизиты ПБО,
  отказ в доступе, чистое состояние нового визита, выбранный ПБО,
  ширины 334, 390 и 406 пикселей.
- Синтаксис `js/app.js` и `js/questions.js` проверен через `node --check`.
- SHA-256 трёх исходных файлов `prototype/` совпадает с сохранённой базой.

Скриншоты проверки: `../../../output/playwright/`.
Скрипты являются функциями `async (page) => ...` для команды Playwright CLI
`run-code`. Порядок: открыть `/demo/index.html`, затем выполнить три сценария
в указанном выше порядке в одной сессии.

Это проверка локального прототипа. Физическое мобильное устройство, Safari,
добавление файлов фото и реальная генерация PDF не проверялись.
Границы соответствия записи перечислены в `../README.md`.
