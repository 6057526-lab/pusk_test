# Текущая мобильная версия — рабочая копия

- ID: `current-mobile`. Это подготовительная доработка базы, не UX-эксперимент X2.
- Создана 2026-09-23 из `prototype/`. Исходные SHA-256: `../../docs/baseline-sha256.json`.
- Задача пользователя: довести текущий вариант до записанного мобильного приложения,
  дать пройти путь и записать второе видео для сравнения.
- Источники: записи `20260922-1210-28.0597171.mp4`, `20260922-1429-38.7859263.mp4`,
  «КАНОН-виджеты (1).pdf». Таймкоды и ограничения: `../../docs/video-audit/README.md`.
- Презентационные UX-улучшения не применялись.

## Запуск и запись

Открыть `index.html` напрямую или через `../../demo/index.html`.
При локальном сервере: `/variants/current-mobile/index.html`.
DEV позволяет выбрать размер 334×732 (первая запись), 406×864 (вторая) или
390×664 (PDF). На телефоне приложение занимает доступный viewport.
Для чистого видео открыть «Открыть без DEV». Перезагрузка сбрасывает сеанс.

1. Главная → бургер → Внесение визитов → Аудит по Безопасности пищи New.
2. Проверить дату, открыть календарь по иконке, выбрать ПБО через поиск.
3. При желании открыть ссылку чек-листа и просмотр вопросов, затем вернуться.
4. Нажать «Заполнить визит», открыть задачу ознакомления, подтвердить согласие.
5. Из задач открыть форму заполнения.
6. Пройти некритические вопросы, раскрыть причины «Нет», добавить комментарий.
7. Сохранить и вернуться через задачу; проверить сохранение ответов в этом сеансе.
8. Попытаться завершить неполный визит, увидеть список ошибок.
9. Заполнить оба раздела, завершить, проверить окно «Факт фальсификации» и отмену.
10. Подтвердить завершение, дождаться задачи результатов, открыть отчёт и файл.

## Что восстановлено

- 48 вопросов: 39 некритических в пяти блоках и 9 критических. В том числе
  разные 24.FS и 24.FS24 и аналогичные номера раздела хранения.
- Тексты и варианты ответов из просмотренных кадров. Номер секунды источника
  есть у каждого вопроса в `js/questions.js`. Транскрипция визуальная;
  побуквенную сверку следует продолжить при сравнении нового видео.
- Причины чекбоксами для 10.FS–12.FS, именно эти раскрытые списки видны в записи.
- Сохранение ответов, нескольких причин и комментариев между разделами и задачами.
- Календарь, связь выбранных реквизитов с задачей и отчётом, переход через задачи
  после соглашения, подтверждение завершения с фактом фальсификации.
- Многостраничное HTML-представление отчёта, масштабирование и карточка документа.
- Фильтр ПБО в отчётах, сведения Test Hub, зафиксированный отказ в доступе.
- Размеры, типографика и плотность основной формы приближены к записи 334×732.

## Границы точности

- Полностью восстанавливается показанный аудит безопасности пищи. Другие
  чек-листы и ветки поддерживающего визита пока унаследованы из X1; их нельзя
  считать полноценными копиями всех реальных форм.
- Нижняя часть соглашения доступна в записи. Полного утверждённого текста нет;
  это не юридическая копия политики.
- Кнопки «Дополнительная информация» видны, но содержимое в записи не раскрыто.
  В этой копии они отключены, новые пояснения не придуманы.
- Поведение диалога добавления фото не записано: используется локальный файловый
  выбор с предпросмотром, без отправки данных. Это техническое допущение.
- Напоминания, лента, часть служебных кнопок остаются только визуальными элементами.
- Отчёт формируется из введённых ответов как HTML на пяти страницах. Это не
  реальный PDF и не точное воспроизведение печатной вёрстки исходного отчёта.
  Баллы и проценты не вычисляются: их правила не установлены. Свойства документа
  (включая 30 КБ и время) — фиксированный образец из видео, не размер HTML.
- Закрытие процесса возвращает к задачам и убирает задачу результатов; это
  локальное допущение, окончательное закрытие в видео не подтверждено.
- Данные живут только в памяти вкладки. Сервер, авторизация, реальные права,
  сохранение после перезагрузки и бизнес-расчёты не реализованы.
- DEV сохраняет отдельные вкладки iframe в памяти. Переноса шага и данных
  между вариантами нет; синхронное сравнение путей не реализовано.

Эта версия предназначена для следующего прогона и видеосверки. Нельзя объявлять
её пиксельно точной копией или законченной реализацией реальной системы.
