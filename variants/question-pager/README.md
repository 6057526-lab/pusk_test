# X2 — по одному вопросу (ранее X4)

13 октября 2026 пользователь переименовал этот вариант в X2 для дальнейшего
сравнения с новым X3. Путь, стабильный ID и ключ черновика не изменены.
Упоминания X4 ниже описывают историю изменений до переименования.

ID: `question-pager`, создан 2026-09-23. Независимая копия
`variants/visit-workspace/`; SHA-256 исходных файлов: `source-sha256.json`.
Цель пользователя: проверить горизонтальное перелистывание вопросов при
нескольких верхних группах и вложенных разделах. Это эксперимент для сравнения,
не доказанное улучшение скорости работы менеджера.

## Что изменилось

- Один вопрос на экране, «Назад / Далее». Ответ не переключает экран автоматически.
- Главная с метриками ПБО → меню «Внесение визитов» → чек-лист и реквизиты
  → открытая задача ознакомления → согласие → сразу вопрос → проверка
  → задача результатов → отчёт и экран документа. Задача заполнения создаётся
  в фоне и позволяет вернуться к сохранённому черновику.
- Свайп влево/вправо дополняет кнопки. Жесты на полях, кнопках, label, summary
  и возле краёв экрана исключены; вертикальная прокрутка оставлена браузеру.
- Группа, подраздел, номер вопроса в подразделе и общий прогресс видны сверху.
- Смена подраздела и группы отмечена названием действия на кнопке перехода.
- «Все разделы»: оглавление группа → подраздел → конкретный вопрос с ответом.
  Оно строится из массива групп, а не ограничено критическими/некритическими.
- Можно пропускать вопросы и возвращаться. При завершении показан первый пропуск.
- Исправление 2026-09-23: при заполненных 48/48 кнопка «Проверить и завершить»
  открывает проверку с любого вопроса, в том числе после возврата из оглавления.
  Ранее это работало лишь с последнего вопроса по порядку.
- При возврате сохраняются ответы, причины, комментарии и позиция прокрутки
  вопроса в текущем сеансе. После перезагрузки восстанавливается номер вопроса,
  но не позиция прокрутки. Комментарий с текстом раскрывается при возврате.
- Собственный localStorage: `pusk:question-pager:v1`. Сброс в DEV и внутри X4
  после подтверждения удаляет только этот ключ.

## Запуск

`../../demo/index.html` → «X2 · По одному вопросу». Главная → меню → Внесение
визитов → чек-лист → реквизиты → задача ознакомления → политики → вопрос
→ проверка → подтверждение → задача результатов → отчёт → экран документа.
«Все разделы» открывает оглавление из любого вопроса.
Экран документа показывает страницы настоящего PDF; «Скачать PDF» создаёт PDF
с текущими реквизитами, результатом, всеми ответами, причинами и комментариями.
Содержимое исходных 48 вопросов и допустимые ответы не изменены.

## Ограничения

Один локальный визит, без серверной синхронизации и защиты от одновременной
записи в нескольких вкладках. Квота localStorage ограничивает фотографии;
при ошибке сохранения показывается предупреждение. Политики, неизвестные
дополнительные сведения и оставшиеся служебные экраны сохраняют ограничения X3.
Меню КпП сокращено до Dashboard ПУСК, Внесение визитов и Задачи.
Реальный реестр ПБО с датами открытия/IPUR не подключён; в выпадающем списке
используется демонстрационный список доступных предприятий.
Ролевые права на параметры чек-листа и потребность в оповещениях не согласованы.
Оценка демонстрационная, по решению пользователя от 13 октября: доля «Да»
от всех вопросов; «Частично Да» и «Неактуально» не увеличивают числитель.
Критический «Нет» или фальсификация — неудовлетворительно, иначе — удовлетворительно.
Производственная формула и веса не определены.
PDF включает фотографии JPEG/PNG; другие форматы отмечаются сообщением в отчёте.
Проверены обработчики touch-pointer; физические iPhone/Android, конфликт жестов
с ОС, экранная клавиатура и screen reader требуют отдельной проверки.
В реальном наборе две группы. Семь групп проверяются только тестовой подменой
данных в браузере, без добавления вымышленных вопросов в приложение.

## Проверки

Playwright CLI `qa.js`: один вопрос, отсутствие автоперехода, сохранение,
возврат, свайп и исключение поля ввода, восстановление после перезагрузки,
все 48 вопросов, переход в другую группу, завершение и отчёт.
`qa-structure.js`: семь групп с подразделами, ширины 334/390/406, футер,
запуск X1/X4 и прямая ссылка X4. Соседние копии сохранены для прямого запуска.
`qa-business.js`: выпадающий список, открытие задачи, согласие → вопрос,
демо-расчёт 44/48 = 91,7%, критический «Нет», результат, скачивание PDF,
переключение двух вариантов и сброс только X4.
`qa-results.js`: все «Да», некритический «Нет», фальсификация,
незаполненный критический вопрос и исправленная оценка.
Скачанный PDF проверен по тексту и визуально (первая/последняя страницы).
Скриншоты: `../../output/playwright/x4-*.png`.

## Обновление 2026-10-13

По прямому указанию пользователя обновлён существующий X4 по презентации
`Проведение_визитов_замечания_121026.pptx`, слайды 2–6. Источник самой копии
не изменился; исходные вопросы и ответы остались прежними. Заголовок реквизитов
«Заполнить информацию по визиту», уточнённая подсказка 60 дней/IPUR,
доступные ПБО в выпадающем списке, параметры для просмотра, меню КпП,
сводка проверки и завершённого визита, скачиваемый PDF. Dashboard на первом
слайде отмечен «В проработке» и по нему изменений не делалось.
В оболочке отображаются только X1 и X4, по умолчанию — X4.
Библиотеки PDF и кириллический шрифт находятся в `assets/vendor/`,
собственные источники и лицензии описаны в README этого каталога.

## Дополнение 2026-10-13: жесты, навигация и предварительный отчёт

- Свайп касанием/пером и горизонтальное перетаскивание мышью меняют вопрос.
  Жест всегда листает вопросы, даже при 48/48; кнопка «Проверить и завершить»
  сохраняет свой переход к проверке. Вертикальная прокрутка и поля исключены.
- «Назад» из оглавления возвращается к текущему вопросу заполнения и его прокрутке.
- В проверке есть все ответы, причины и комментарии с переходом для исправления.
  Предварительный PDF можно посмотреть перед завершением и из окна подтверждения.
  Это настоящий PDF, отмеченный как предварительный; его открытие/скачивание
  не завершает визит. После исправлений формируется новый документ.
- Страницы настоящего PDF отображаются локальной PDF.js внутри приложения.
  Доступны скачивание и открытие отдельно; рендер проверен в браузере.
  Из просмотра можно вернуться к проверке либо открытому подтверждению.
- ПБО выбирается в панели с поиском по номеру/названию и отметкой выбора.
  Указатель хранит только значение из демонстрационного списка. Escape закрывает
  панель, фокус ограничен её элементами. Календарь даты сохранён.
- На согласии убраны неподключённые книга, ноль, три точки, напоминания и лента.
  Это очистка X4; исходный X1 не затронут. Автопереход после ответа не добавлен.

Проверки: `qa-navigation-preview.js` — возврат, настоящий drag мышью,
предварительный PDF, редактирование после просмотра, новое содержимое файла,
возврат к подтверждению. `qa-entry-controls.js` — поиск и выбор ПБО,
Escape, календарь, сохранение реквизитов и чистый экран согласия.
`qa-preview-isolation.js` — генерация PDF при переключении на X1 и корректный
просмотр при возврате в X4 без завершения визита.
Дополнительно браузер с эмуляцией touch сгенерировал реальные pointer-события
горизонтального жеста. Физические устройства по-прежнему не проверены.
