# Локальные ресурсы X3

Собственные копии, не ссылки на ресурсы другого варианта:

- `icons/`: Phosphor Icons regular, @phosphor-icons/core 2.1.1, MIT.
  Получены 13.10.2026 из официального пакета через jsDelivr:
  https://cdn.jsdelivr.net/npm/@phosphor-icons/core@2.1.1/assets/regular/
  Лицензия: `icons/LICENSE`.
- `fonts/Inter.ttf`: Inter variable (opsz,wght), Google Fonts / Rasmus Andersson,
  SIL OFL. Источник: https://github.com/google/fonts/tree/main/ofl/inter,
  получен 13.10.2026. Лицензия: `fonts/OFL.txt`.
- `vendor/`: собственные копии pdf-lib 1.17.1 (MIT), @pdf-lib/fontkit 1.1.1
  (MIT), Noto Sans Regular (SIL OFL) и PDF.js 3.11.174 (Apache 2.0), взяты
  из question-pager на дату source-sha256.json. Лицензии рядом с файлами.
- `policy.json`: точный текст политик agreement-food из question-pager/index.html.

Фоновая синхронизация и внешние шрифты/ресурсы при запуске не требуются.
