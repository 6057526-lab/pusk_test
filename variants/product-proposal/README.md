# X2 — предложение для продакта

- ID: `product-proposal`, создан 2026-09-23.
- Источник: независимая копия HTML/CSS/JS `variants/current-mobile/`.
  SHA-256 исходных файлов: `source-sha256.json`.
- Основание: презентация «Мобильный чек-лист — предложение для продакта»
  из задачи «Подготовить презентацию мобильного W» от 7 сентября.
  Пользователь сообщил, что предложение понравилось продакту, и разрешил
  сделать кликабельный вариант.
- Цель: сравнить тот же аудит безопасности пищи с подготовительной мобильной базой.

## Реализовано по презентации

| Слайды | Изменение |
|---|---|
| 4 | Сохранён календарь; поиск ПБО списком, раскрываемые сведения, пустой результат |
| 5 | Два именованных раздела, прогресс разделов и визита, число пропусков |
| 6 | Крупные контролы и карточки вопросов, футер вне прокрутки с safe area |
| 7 | Компактная сводка, следующий пропуск с переходом между разделами, ошибки у ответов |
| 8 | Карточки задач ниже 768px: название, автор, дата, срок при наличии |
| 9–10 | Проверка заполнения, возврат к разделам, затем подтверждение с фальсификацией |

Вопросы и варианты ответов, причины, комментарии и фото наследуются из базы.
Новые правила оценки не введены. Конкретные цвета и размеры карточек — реализация
схем презентации, не утверждённые пиксельные макеты.

## Запуск и сценарий

`../../demo/index.html` → «X2 · Для продакта» либо собственный `index.html`.
Главная → меню → Внесение визитов → Аудит по Безопасности пищи New → дата и ПБО
→ Заполнить визит → задача ознакомления → согласие → задача заполнения.
Проверить неполный визит, перейти к пропускам, заполнить 39 + 9 вопросов,
проверить сводку, подтвердить завершение, открыть задачу результатов и отчёт.
«Сохранить» возвращает к задаче; черновик живёт только в памяти этой вкладки.

## Ограничения

Это X2, а не X3 с дополнительным перепроектированием процесса. Главная и отдельные
отчётные сценарии не перепроектированы. Дополнительная информация, политики,
другие чек-листы и расчёты имеют ограничения базы (`../current-mobile/README.md`).
Ссылка на README является документацией, не зависимостью кода.
Отчёт — HTML-имитация, настоящий PDF не создаётся. Серверного сохранения,
авторизации и переноса данных между вариантами нет.
